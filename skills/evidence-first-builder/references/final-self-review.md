# Final Self-Review

Run after research/execution and before delivery.

## Evidence

- Are time-sensitive claims current enough?
- Do cited sources actually support the claims?
- Did duplicate secondary pages create false confidence?
- Did I distinguish observed facts, inference, preference, and unknowns?
- Did I search for disconfirming evidence or common failure modes when the decision matters?

## Reuse and scope

- Did I inspect mature existing projects/apps/libraries/workflows first?
- Did I reject reuse for a real constraint rather than a preference for custom work?
- If I built new, did I preserve proven patterns and minimize scope?
- Did I add unnecessary dependencies, infrastructure, or complexity?

## Commercial independence

- Would the ranking change if sponsored/promoted results disappeared?
- Did vendor/affiliate language enter the reasoning as evidence?
- Did I miss a materially better open-source, self-hosted, cheaper, or privacy-preserving alternative?
- Did I treat commercial and open-source candidates by the same fit/evidence standard?
- Are hidden costs, lock-in, telemetry, or data-use terms relevant and disclosed?

## Security, privacy, and license

- Are credentials/secrets handled safely?
- Is telemetry/data flow acceptable?
- Are install scripts/binaries trustworthy enough for the requested action?
- Is the license compatible with intended use?
- Is rollback/recovery available when a change is risky?

## Verification

- What observable evidence proves the result?
- Did I test the requested behavior rather than only command success?
- Is the verification status labeled precisely?
- Did I preserve unrelated existing behavior?

## Composition and efficiency

- Did a more specific active skill already own part of this workflow?
- Did I duplicate repository reads, web searches, execution, or tests without a new reason?
- Did I pass compact conclusions and constraints instead of a research transcript to another agent/skill?
- Did I stop researching once additional sources stopped changing the decision?

## Final response

- Lead with the decision/result.
- Keep research details proportional to user need.
- Show meaningful tradeoffs, not every candidate found.
- Use the recommendation card for consequential choices.
- State unresolved uncertainty without fake precision.
